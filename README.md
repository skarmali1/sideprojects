# Seattle Kids Activities Planner

A simple, mobile-friendly web app to plan weekly activities for your kids in the Seattle area.

## Features

- **Weekly Planner** - Plan activities for each day of the week
- **65+ Activities** - Curated Seattle-specific activities for ages 2 & 4
- **Quick Activities** - 25+ activities that take just 10-15 minutes at home
- **Daily Rotation** - Activities automatically refresh each day
- **Manual Shuffle** - Click to see different activity suggestions anytime
- **Favorites** - Save activities you love
- **Filter by** - Category, age, free/paid

## How to Use

### Option 1: Download and Open Locally (Easiest!)

1. Download these 3 files from your repo:
   - `index.html`
   - `app.js`
   - `styles.css`

2. Put them all in the same folder

3. Double-click `index.html` to open in your browser

4. **That's it!** Works completely offline, saves all your data locally

### Option 2: Set Up GitHub Pages

1. Go to your GitHub repo: `https://github.com/skarmali1/sideprojects`

2. Click **Settings** → **Pages**

3. Under "Branch", select `claude/seattle-kids-activities-iOWxC`

4. Click **Save**

5. Wait a few minutes, then access at: `https://skarmali1.github.io/sideprojects/`

### Option 3: Use on Your Phone

1. Open the files on your computer using Option 1
2. Bookmark the page
3. Or: email yourself the 3 files, save to your phone, open index.html
